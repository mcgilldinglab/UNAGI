Manuscript Figures
==================

This section provides the script used to reproduce the figures used in the manuscript. Noted that some of the figures are not generated by the scripts (e.g. Fig. 3a) 

Programmatic Figure API
-----------------------

The `UNAGI.plotting.manuscript_figures` module provides reusable plotting functions
aligned with manuscript-style panels, including:

- Stage-wise UMAP panels and cell composition bars.
- Marker dotplots and trajectory graph visualization.
- Perturbation result extraction and ranked bar plotting.
- In-silico versus observed expression comparison plots.
